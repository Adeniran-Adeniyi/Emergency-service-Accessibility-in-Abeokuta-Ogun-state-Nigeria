# Emergency-service-Accessibility-in-Abeokuta-Ogun-state-Nigeria

> This project explores access to emergency services across Abeokuta North and Abeokuta South, Ogun State, Nigeria. It uses geospatial analysis and network analysis to examine the locations of fire and police stations, their accessibility through the road network, and wards that may face longer travel distances to emergency facilities.

## GeoDev Lab Africa, Cohort One
> *prepared by: Adeniyi Damilola Adeniran*

## The Question 

> Which wards in Abeokuta North and Abeokuta South have poorer access to emergency services, and how can GIS help identify areas that may need better coverage?
